# datasheets/
Manufacturer datasheet PDFs for the parts whose footprints, pinouts or design
numbers were taken from them (LM1875, LM317, TL072, MMBF5457, 2N5457, J111–J113,
KBP410G + KBP family, 1N4007, 1N4148, 1N4148W, VTL5C1, AnTek AS-0524) — ~15 MB.
`SOURCES.md` is the manifest: source URL, revision, what each sheet backs, and a
SHA-256 prefix so the exact revision used here can be told apart from a newer one.
