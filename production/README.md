# production/

`smd/` — the JLCPCB order package for the mixed SMD/THT board: zipped Gerbers + drill,
assembly BOM with LCSC part numbers, pick-and-place file, assembly drawing. Generated by
`kicad/gen/fab_jlcpcb.py` (or the whole chain: `kicad/gen/build.sh smd`); see
`smd/README.md` for the order settings. `CHECKLIST.md` is the pre-order gate.
